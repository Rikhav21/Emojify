# Emojify

Emojify is my attemptat turning a lot of the english words on the internet into emojsi. I feel like there should already be a tool to do that, but I think that this is actually pretty fun to decode what it means, although it might not do a lot of words, because I did not know how to do the emoji forms of words like "a" or "the".

## How to use it

All you have to do is open the copy paste file, create a new bookmark in your browser, and copy and paste it as one line in the URL box, and then when you want to use it, you only have to press the bookmark, and everything should convert automatically.
